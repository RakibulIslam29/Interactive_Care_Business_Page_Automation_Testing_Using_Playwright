
# Automated testing of Interactive Cares business page using Playwright with Page Object Model (POM)

This project aims to automate testing of the Interactive Cares business page using Playwright, leveraging the Page Object Model (POM) design pattern. It includes tests for verifying UI elements, functionality such as search boxes, "Get in Touch" button interactions, and the chatbot.


## Prerequisites
Ensure you have the following installed:
 - Node.js (v12+)
 - npm (Node Package Manager)
 - Playwright


## Installation

Install my-project with npm
1. Clone the repository:
```bash
  https://github.com/RakibulIslam29/Interactive_Cares_Business_Page_Automation_Testing_Using_Playwright.git

```
2. Install dependencies:
```bash
npm install

```
## Running Tests

To run the automated tests using Playwright, use the following command:

1. Run All
```bash
  npm run check-all-functionality
```
2. Check Business Paage UI
```bash
  npm run business-paage-UI-check
```
3. Check Search Box Functionality
```bash
  npm run check-search-box-functionality
```
4. Check Get in Touch Button Functionality
```bash
  npm run check-get-in-touch-button-functionality
```
5. Check Interactive Caress Chatbot Functionality
```bash
  npm run check-get-in-touch-button-functionality
```
